> 设计文档 | 2026-06-01 | 状态：待评审

## 概述

两个独立功能的聚合：
1. **辐射状柱状图** — 替代 Sunburst 旭日图，极坐标径向柱状图显示文件类型+大小分布
2. **灵动岛修复** — 文字可见性修复 + CompactLeading/CompactTrailing 刘海包裹布局

## §1 辐射状柱状图 (RadialBarChart)

### 1.1 设计目标

替代现有三层 SunburstChart，用极坐标辐射状柱状图展示文件分类。保留两层：类型（柱子）+ 大小（柱内分段）。

### 1.2 布局规格

```
每根柱子由圆心向外辐射，柱高 = 该类型文件总大小
柱内分 4 段颜色（由深到浅）：
  ██ 巨型文件 (>1GB)    — 最深色
  ██ 大文件 (100MB-1GB)
  ██ 中等文件 (10-100MB)
  ░░ 小文件 (<10MB)     — 最浅色

8 根柱子等角度均分 360°（只显示 size > 0 的类型）
圆心显示总计标签
```

### 1.3 组件接口

```swift
struct RadialBarChart: View {
    let data: RadialBarData  // build from categorized files
    // 复用 SunburstData.build(from:) 逻辑，输出改为 RadialBarData
}
```

### 1.4 数据模型

```swift
struct RadialBarData {
    let bars: [RadialBar]       // 每个文件类型一根柱
    let totalSize: Int64
}

struct RadialBar: Identifiable {
    let id = UUID()
    let category: FileItem.FileCategory
    let segments: [RadialBarSegment]   // 4 段大小分层
    let totalSize: Int64
    let fileCount: Int
}

struct RadialBarSegment: Identifiable {
    let id = UUID()
    let sizeLabel: String     // "巨型文件 (>1GB)"
    let size: Int64
    let opacity: Double       // 颜色深浅 0.3—1.0
}
```

### 1.5 交互

- 点击柱子 → popover/tooltip 显示类型名 + 各段大小明细
- 扫描后 spring 动画弹出
- 无旋转/缩放手势（极坐标柱状图不适合旋转）

## §2 灵动岛修复

### 2.1 问题根因

1. **文字不可见：** NotchHUDView 使用 `.foregroundColor(.secondary)` / `.primary` 语义色，在 DynamicNotchKit 暗色面板上渲染为接近面板背景的暗色，肉眼看不到文字。只看到绿点是因为 Circle 用了绝对色 `.green`/`.orange`/`.red`。

2. **未启用 Compact 槽位：** 当前 `DynamicNotch<NotchHUDView, EmptyView, EmptyView>` 把两个 compact 槽位填了 `EmptyView`，刘海两侧无内容。

### 2.2 修复方案

**配色修复：** 所有文字改用绝对色 `Color(white: 0.9)`（接近白色但不过曝），数值用 `Color.white`。

**刘海包裹布局：** 利用 DynamicNotchKit 三槽模型：

```
compactLeading        Notch        compactTrailing
┌─────────────────┐               ┌─────────────────┐
│ ⏺ CPU  23%      │  (notch cut) │ ⏺ RAM  45%      │
└─────────────────┘               └─────────────────┘
```

- `DynamicNotch<NotchHUDView, CompactCPUView, CompactRAMView>`
- `CompactCPUView`：⏺ 圆点(颜色分级) + "CPU" + "23%"，约 60pt 宽
- `CompactRAMView`：⏺ 圆点(颜色分级) + "RAM" + "45%"，约 60pt 宽

### 2.3 波及文件

| 文件 | 改动 |
|------|------|
| `UI/Components/DynamicIslandController.swift` | 修改 Generic 参数；新增 CompactCPUView/CompactRAMView；文字颜色修复 |

### 2.4 注意

- DynamicNotchKit v1.1.0 的 `@Entry` 宏兼容性问题已在 v0.3 修复（`scripts/build-dmg.sh` 自动处理），本次不涉及 SPM 依赖变更
