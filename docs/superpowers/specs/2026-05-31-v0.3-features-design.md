## §1 磁盘分析性能修复

### 根因

[DiskAnalyzerView.analyze()](../../Sources/MacCleanerApp/Modules/DiskAnalyzer/DiskAnalyzerView.swift#L207-L219) 调用旧版 `FileScanner.scanDirectory()`，该方法全量物化所有文件到数组（无流式、无 autoreleasepool），正是 v0.1 60GB 内存泄漏的同一根因。

### 修复

在 `UnifiedScanner` 的 `processBatch()` 中添加第四路分类管道：

```
流式遍历（一次 for-in NSEnumerator）
  ├─→ JunkDetector.rules 匹配    ──→ junkResults
  ├─→ 大小过滤 >50MB            ──→ largeFiles
  ├─→ 大小分桶                   ──→ duplicateBuckets
  └─→ 按扩展名分类               ──→ categorizedFiles  ← NEW
```

- `FileItem.FileCategory.from(extension:)` 已存在，直接复用
- `scan()` 返回值从 3 元组扩展为 4 元组
- `DiskAnalyzerView.analyze()` 改为调用 UnifiedScanner，获取 categorizedFiles → 构建 SunburstData

### 波及文件

| 文件 | 改动 |
|------|------|
| `Services/UnifiedScanner.swift` | `processBatch()` 新增分类收集；`scan()` 返回增加 `categorized` 字段 |
| `Modules/DiskAnalyzer/DiskAnalyzerView.swift` | `analyze()` 改用 UnifiedScanner |

## §3 回收站（TrashBin）

### 存储位置

`~/Documents/MacCleanerApp 回收站/` — 用户可见目录。

### 存储结构

```
~/Documents/MacCleanerApp 回收站/
├── .trash-manifest.json       ← 元数据清单
└── <uuid>/                    ← 每批删除一个子目录
    ├── file1.dmg
    └── file2.log
```

### 清单 schema

```json
{
  "items": [
    {
      "id": "uuid-string",
      "originalPath": "/Users/xxx/Downloads/file.dmg",
      "trashPath": "...回收站/uuid-dir/file.dmg",
      "size": 1234567,
      "fileName": "file.dmg",
      "deletedAt": "2026-05-31T10:00:00Z",
      "expiresAt": "2026-06-07T10:00:00Z"
    }
  ]
}
```

### 新文件

| 文件 | 类型 | 职责 |
|------|------|------|
| `Services/TrashManager.swift` | actor | 移入/恢复/彻底删除/定时清理/读写 manifest |
| `Modules/TrashBin/TrashBinView.swift` | View | 回收站页面：列表 + 倒计时 + 恢复 + 彻底删除按钮 |

### TrashManager API

```swift
actor TrashManager {
    let recycleBinURL: URL  // ~/Documents/MacCleanerApp 回收站/
    
    func start()           // 加载 manifest，启动定时清理 Timer
    func moveToTrash(_ urls: [URL]) async throws -> [TrashItem]  // 文件移入回收站
    func restore(_ item: TrashItem) async throws               // 移回原路径
    func permanentlyDelete(_ item: TrashItem) async throws     // trashItem 到系统废纸篓
    func getItems() -> [TrashItem]                              // 读取所有回收站条目
    func purgeExpired() async                                   // 过期条目 → trashItem
}
```

### 安全红线兼容

- 移入回收站：`FileManager.moveItem`（同卷 rename，原子操作，零数据拷贝）
  - `moveItem` ≠ `removeItem`——文件完整保留，仅路径变更，可随时恢复
- 到期清理：走 `trashItem` 移入系统废纸篓（不调用 `removeItem`）
- 彻底删除：走 `trashItem` 移入系统废纸篓（给系统级后悔机会）
- **全流程无 `removeItem` 调用**，严格遵守安全红线

### 提示流程

```
用户点击删除
  → 🔔 确认弹窗: "确定要删除 N 个文件吗？"
    → 用户确认
      → 文件移入回收站
      → 🔔 提示: "✅ 已移入「MacCleanerApp 回收站」，保留 7 天后自动转至系统废纸篓
                   可在回收站页面恢复文件或彻底删除"
        → 用户可去回收站页面:
          ├── 🔄 恢复 → 移回原路径 → 🔔 "已恢复"
          └── 🗑️ 彻底删除 → trashItem() → 🔔 "已移入系统废纸篓，可在废纸篓中还原"
```

### 定时清理

- `TrashManager.start()` 启动 Timer，每 12 小时扫描一次
- 遍历 manifest 中 `expiresAt < now` 的条目
- 逐个 `trashItem` → 系统废纸篓
- 从 manifest 移除已清理条目
