## §1 辐射状柱状图 (RadialBarChart)

### 1.1 目标
替代现有三层 SunburstChart，极坐标辐射状柱状图，保留类型+大小两层。

### 1.2 布局

```
8 根柱子等角度均分 360°（只显示 size > 0 的类型）
每柱由圆心向外辐射，柱高 = 该类型总大小
柱内 4 段颜色深浅：
  ██ 巨型文件 (>1GB)
  ██ 大文件 (100MB-1GB)
  ░░ 中等文件 (10-100MB)
  ░░ 小文件 (<10MB)
圆心 = 总大小标签
```

### 1.3 数据模型

```swift
struct RadialBarData { let bars: [RadialBar]; let totalSize: Int64 }
struct RadialBar: Identifiable { let category: FileItem.FileCategory; let segments: [RadialBarSegment]; let totalSize: Int64; let fileCount: Int }
struct RadialBarSegment: Identifiable { let sizeLabel: String; let size: Int64; let opacity: Double }
```

### 1.4 交互
- 点击柱子 → popover tooltip（类型名+各段大小明细）
- spring 弹出动画
- 无旋转/缩放手势

## §3 进程管理 (ProcessManager)

### 3.1 C 形态：侧边栏完整列表 + 菜单栏快速入口

### 3.2 技术栈

| 数据 | API |
|------|-----|
| 运行中应用 | `NSWorkspace.shared.runningApplications` |
| 进程内存 | `proc_pidinfo(PROC_PIDTASKINFO) → pti_resident_size` |
| 进程 CPU | `proc_pidinfo → pti_total_user + pti_total_system`，两次采样差分 |
| GUI 正常退出 | `NSRunningApplication.terminate()` |
| GUI 强制退出 | `NSRunningApplication.forceTerminate()` |
| 后台进程终止 | `kill(pid, SIGTERM)` → 3s timeout → `kill(pid, SIGKILL)` |
| 进程图标 | `NSRunningApplication.icon` |
| 系统进程白名单 | Dock, WindowServer, loginwindow, SystemUIServer, Finder |

### 3.3 侧边栏页面 ProcessManagerView

- 搜索栏 + 刷新按钮 + 分类筛选（GUI/后台/全部）
- 表格列：图标 | 进程名 | CPU% | 内存 | PID | 操作
- 系统进程标记 🔒，按钮置灰
- 2 秒自动刷新（复用 SystemMonitor Timer 模式）
- 终止操作：确认弹窗 → 执行终止 → 结果提示

### 3.4 菜单栏快速入口

灵动岛常驻胶囊上新增进程图标，点击弹出 Top-5 CPU 消耗列表（NSPopover），底部"打开完整进程管理 →"跳转侧边栏。

## §4 软件卸载 (AppUninstaller)

### 4.1 参考

Pearcleaner (13k★) 的卸载引擎：Bundle ID 匹配 + `~/Library` 12 个位置深度残留扫描。

### 4.2 扫描逻辑

```
1. 列出 /Applications/*.app + ~/Applications/*
2. 解析 Info.plist → Bundle ID + 版本 + 应用名
3. 在 12 个 ~/Library 子目录搜索 Bundle ID 匹配：
   - Application Support/<BundleID>
   - Caches/<BundleID>
   - Preferences/<BundleID>.plist
   - Containers/<BundleID>
   - Group Containers/<BundleID>  (需解包 Entitlements)
   - Logs/<BundleID>
   - Saved Application State/<BundleID>*.savedState
   - WebKit/<BundleID>
   - Cookies/<BundleID>.binarycookies
   - HTTPStorages/<BundleID>
   - LaunchAgents/<BundleID>.plist
   - Mail/<BundleID>
4. 聚合结果 → 展示给用户
```

### 4.3 卸载流程

```
列表（图标 + 名称 + 版本 + Bundle ID）
  → 点击应用 → 深度扫描残留
  → 展示清单（应用本体 + 所有残留文件，每项可勾选）
  → 用户确认
  → TrashManager.moveToTrash() → 灵动岛 "卸载完成"
```

## §6 Bug 修复：垃圾详情卡死

### 6.1 根因
`JunkCleanerView.swift:262` — `detailFiles = files.sorted { $0.size > $1.size }` 在点击 info 按钮时同步执行，大文件量下（10 万+）阻塞主线程。

### 6.2 修复
把 sort 放到 `Task.detached(priority: .background)` 执行，完成后回主线程赋值。

### 6.3 波及

| 文件 | 改动 |
|------|------|
| `Modules/JunkCleaner/JunkCleanerView.swift` | 详情按钮 action 改用异步排序 |
