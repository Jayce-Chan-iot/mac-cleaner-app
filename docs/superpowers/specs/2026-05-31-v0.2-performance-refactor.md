# MacCleanerApp v0.2 — 性能重构 & 新功能设计

> 日期: 2026-05-31 | 版本: v0.2.0

## 1. 统一扫描架构 (UnifiedScanner)

**问题**: 三次全量遍历 Home 目录（JunkDetector + FileScanner + DuplicateDetector 各扫一遍），串行执行，每次用 NSEnumerator.allObjects 全量物化到内存 → 扫描 10+ 分钟，内存 60GB。

**方案**: 一次流式遍历，三路管道分流。

```
UnifiedScanner (actor)
  NSEnumerator 流式，不调 allObjects
  每个文件 → autoreleasepool {
    JunkRule.match(url)    → 匹配归类
    SizeFilter.check(url)  → 大/旧文件
    DupCollector.add(url)  → 按大小分桶
  }
  每 1000 文件冲刷缓冲区
  遍历完成后 SHA-256 验证重复
```

**关键约束**:
- 不调用 NSEnumerator.allObjects
- 每 1000 文件 autoreleasepool + 释放批次
- 中间结果即用即弃（上一步完 = []）
- FileItem 只保留最小字段（路径 + 大小 + 日期）

## 2. 后台扫描不中断

**问题**: Task 绑在 View body 上，切页即取消。

**方案**: Task 移到 AppState 属性，全生命周期。各页只订阅 @Published 状态。

## 3. 图形性能

- Sunburst startAngle: UUID hash → 预计算固定值
- ForEach id: UUID → segment.category 稳定标识
- 柱状图: 移除 GeometryReader

## 4. 垃圾清理详情

每个 JunkCategory 点击展开 → 文件名/路径/大小列表 → 单文件勾选删除 + 右键 Reveal in Finder。

## 5. 菜单栏系统状态

- NSStatusBar + LSUIElement=YES
- 刘海左侧: CPU 温度 (IOKit SMC)
- 刘海右侧: CPU% + RAM% (host_statistics)
- 2s 刷新，点击弹出 HUD 面板
- 目标内存: < 20MB
